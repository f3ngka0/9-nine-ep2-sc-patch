# 《9-nine-：天色天歌天籁音》（Episode 2）简体中文翻译规范与术语表（母语级自然润色版）

## 1. 核心翻译原则：彻底消除“日式翻译腔”，追求母语级中文自然语感
- **以官方日语原文（`jp`）为基准把握准确原意，结合官方英文（`en`）参考句间逻辑与英文专有名词，用真正符合中文母语者说话、吐槽、思考习惯的现代简体中文重新表达。**
- **意译与语序重构优先于死板直译**：在与原文表达意思差距不大的前提下，**大胆调整语序、改写句式、替换日式生硬词组（意译）**，确保台词像是中国人在现实或优质中文轻小说里真正会说出来的话，绝不能让读者感受到日语语法的骨架。
- **零繁体字残留、零台式腔**：全篇严格使用大陆规范简化字，抛弃官繁的错漏与“葛格”“的說”“嗎？”等台式腔调。

### 必须彻底消灭的五大“日式翻译腔”重灾区（附正反对比）
1. **严禁保留日语倒装碎片（句末倒装主语/补语）**
   - 日语习惯先说谓语、再在句尾补一个主语或状语（如 `そもそも自覚がない。俺に。` / `刺激が強すぎるようなの、従来のアンブロシアは` / `イーリスもやむを得ない状況下だけよ、ユーザーを石にしたのは`）。中文母语者绝不会这样把主语孤零零扔在句号后面。
   - ❌ 翻译腔：`再说，压根就没有那份自觉啊。我自己。`
   - ✅ 地道中文：`说到底，我自己压根就没半点实感。`
   - ❌ 翻译腔：`刺激似乎太强了，传统的 Ambrosia。`
   - ✅ 地道中文：`传统的 Ambrosia 对你们来说药性未免太猛烈了。`

2. **严禁照搬日语超长前置定语（“……的……的……的某人/某事”）与名词结句**
   - 日语喜欢把整段叙事塞进定语从句修饰最后一个名词（如 `アーティファクトから得た力を悪用し、人を石にし殺害した……犯人が。` / `普通ではない不可思議な炎を校舎に放ち、火の海にした怪事件その二。` / `超能力によって燃えさかる炎を鎮火した、クラスメイト九條都。`）。中文应当顺着时间与动作逻辑拆开叙述。
   - ❌ 翻译腔：`滥用圣遗物赐予的力量，将活人变成石头杀害的……犯人。`
   - ✅ 地道中文：`那就是滥用 Artifact 的力量，把活人变成石头残忍杀害的……真凶。`
   - ❌ 翻译腔：`我就读的白泉学园里，有学生对校舍放出了绝非寻常的诡异火焰，将学校化作火海的怪异事件之二。`
   - ✅ 地道中文：`紧接着第二桩怪事，是我就读的白泉学园里，竟有学生放出诡异的火焰，把整座教学楼烧成了一片火海。`
   - ❌ 翻译腔：`凭借超能力扑灭熊熊烈焰的，同班同学九条都。`
   - ✅ 地道中文：`而在现场靠超能力扑灭那场熊熊烈火的，正是我的同班同学——九条都。`

3. **严禁机械照搬日式形式体言（“……的是昨天的事”“……是因为……的缘故”）**
   - ❌ 翻译腔：`面对九条那番率直的话语，我故作帅气地回了声『嗯』，这还是昨天的事。`
   - ✅ 地道中文：`昨天听到九条那么直白的一番话，我还装模作样地耍帅回了人家一句『好』。`

4. **严禁生搬硬套日式高频词字面直译（Calques）**
   - `一応`：❌ 严禁机械译为“姑且”（`姑且听说我好像也是……` 极不自然）→ ✅ 按语境译为 **“虽说 / 好歹 / 按理说 / 名义上 / 照理讲”** 或自然融于句中（如 `虽说听人提起，我好像也是什么 Artifact 的使用者……`）。
   - `～に負けて`（如 `同じ班の女子の視線に負け、掃除に集中する`）：❌ 严禁译为“败给了同组女生的目光” → ✅ 译为 **“被同组女生盯得实在没辙，我只好老老实实干活打扫”** / **“扛不住……的眼神”**。
   - `おまけのように`（如 `その中心に九條がいて、その隣に、おまけのように俺がいる`）：❌ `九条站在正中心，而她身旁，还附带着个赠品般的我。` → ✅ `九条是绝对的主角，而站在她旁边的我，充其量也就是个凑数的添头。`
   - `濃い（半月/時間）`：❌ `数一数二浓烈的半个月`（中文不说“浓烈的半个月”）→ ✅ `我这短短的人生里数一数二跌宕起伏——不，是刺激得有点过头的半个月。`
   - `実際、いる。`：❌ `实际上，确实存在。` → ✅ `可现实里还真有这种东西。`
   - `二度見である` / `ドン引きである`：❌ `这就是所谓的看第二眼吧` → ✅ `结结实实地愣了一下，又扭头看了一眼` / `天整个人都看傻了，一脸嫌弃`。
   - `まぁ` / `というか` / `なんというか`：❌ 严禁满篇“嘛，怎么说呢” → ✅ 随口语习惯译为“唉 / 算了 / 倒不如说 / 说白了 / 该怎么讲”或直接省略。

5. **跨文本框（连续条目）的语意衔接**
   - 当原文一句话跨 2～3 个连续条目（`i`, `i+1`）时，必须结合上下文通盘考虑，让每一行在中文里自然衔接、语气连贯，同时严格保持每个 `(s, i)` 条目数量和编号一一对应。

## 4. 引擎标签、格式与标点铁律
1. **完整保留引擎控制标签（严禁删改、漏掉或写错顺序）**：
   - 语音停顿标签 `%D$vl1;` `%D$vl2;` `%D$vl3;` `%D$vl4;` `%D$vl5;`：在中文对应语意停顿/转折处原样保留相同次数和编号的标签。
   - 瞬间/强调标签 `%d;`：原样保留在原位（通常在句首）。
   - 破折号字体标签 `%p-1;%fＭＳ ゴシック;――%p;%fuser;`（以及句尾无闭合标签时的 `%p-1;%fＭＳ ゴシック;――`）：遇到原文含该完整片段时**一字不差地原样保留**！不带该标签的普通破折号用简体中文标准双字破折号 `——`。
2. **引号与标点**：
   - 对话保留直角引号 `「……」`，句内引用保留 `『……』`，省略号统一用成对六点 `……`，波浪号 `～` 适度保留原角色尾音情绪（不可滥用全角英文字母）。
   - **换行对齐规则**：单句不超过约 26 个汉字可不换行；长句请使用 `\n` 手动适度断行，且若属于 `「……」` 对话，**`「` 后接 `\n` 的下一行行首须加一个全角空格 `\u3000`**（例：`「……\n　……」`），旁白无需加全角空格；如某句有 `%D$vl1;` 紧跟在 `\n` 后且后面是说话继续，也按原结构保持美观对齐。
